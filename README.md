# Jamverse — Where Music Finds Its People.
Frontend-only prototype (React + TypeScript + Vite + Tailwind v4 + Lucide). No backend; mock data and created posts, events, requests, profile settings, and interactions persist in localStorage. Creator performance files are simulated and are not uploaded.
## Run
`npm install` then `npm run dev`
## Built routes
/, /discover, /jam-feed, /creator-space, /events (list + map), /events/:id, /host-jam, /communities, /community-chat/:conversationId, /profile, /settings, /leaderboard, /saved, /chat, /notifications, /dashboard
## Not built yet (route to a placeholder)
Search, auth/onboarding, online jam, sponsorship, role switcher.
